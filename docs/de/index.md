## **Home**

JourneyMap ist eine beliebte Karten Modifikation für Minecraft. Ursprünglich wurde sie 2011 von techbrew veröffentlicht. Heute ist sie die beliebteste Karten Modifikation der Welt.

![Background](img/background.jpg){: .center}

JourneyMap beinhaltet eine in-game Minimap und eine Bildschirmgroße Karte, wie auch eine Web variante der Karte, welche im Browser betrachtet werden kann.

Wenn du eine Funktonsreiche und einfach zu bedienende Karten Mod suchst, dann ist JourneyMap einen versuch wert.
Du kannst sie auf [CurseForge](https://www.curseforge.com/minecraft/mc-mods/journeymap) oder [Modrinth](https://modrinth.com/mod/journeymap) finden, und sie wie jede andere [Fabric](https://fabricmc.net/), [Quilt](https://quiltmc.org), [Forge](https://forums.minecraftforge.net/) oder [NeoForge](https://neoforged.net/) Modifikation einfach installeren.
