# **Conditions d'utilisation de Mappy2**

Last updated: June 16, 2026

Mappy2 est un bot Discord privé et un outil d'administration Web exploité par Mysticdrew pour être utilisé au sein du serveur JourneyMap Discord. Il est utilisé pour prendre en charge la gestion de la communauté JourneyMap, l'assistance à la modération, les commandes personnalisées, la prise de tickets, les flux de travail de support et la création facultative de problèmes GitHub.

Mappy2 est une infrastructure JourneyMap privée. Il n'est pas proposé en tant que plate-forme ou service de robots à usage général pour les serveurs Discord tiers.

En utilisant les fonctionnalités de Mappy2 sur le serveur JourneyMap Discord, en soumettant un ticket traité par Mappy2 ou en utilisant le tableau de bord Web Mappy2 en tant que personnel JourneyMap autorisé, vous acceptez ces conditions.

Mappy2 est exploité par Mysticdrew. Pour toute question, assistance, demande de politique ou demande de données, contactez Mysticdrew sur le [serveur Discord JourneyMap](https://discord.gg/eP8gE69).

## **Utilisation autorisée**

Mappy2 est destiné uniquement à être utilisé dans le serveur JourneyMap Discord et les workflows d'administration JourneyMap associés.

Les membres de JourneyMap Discord peuvent interagir avec Mappy2 via des fonctionnalités du serveur telles que les commandes, les flux de travail de modération, la prise de tickets et les processus d'assistance mis à disposition sur le serveur.

Seul le personnel JourneyMap autorisé peut accéder au tableau de bord Web Mappy2, configurer Mappy2, gérer les tickets, gérer les commandes, utiliser les fonctionnalités d'administration ou déclencher les fonctionnalités d'intégration GitHub.

Vous ne pouvez pas inviter, copier, configurer ou utiliser Mappy2 pour un autre serveur Discord à moins que Mysticdrew ne donne une autorisation explicite.

## **Responsabilité du personnel de JourneyMap**

Le personnel autorisé de JourneyMap est responsable de l'utilisation appropriée de Mappy2. Cela comprend :

- Choisir les canaux, rôles, journaux, panneaux de tickets, commandes et référentiels GitHub de JourneyMap Discord que Mappy2 utilise.
- S'assurer que les questions des tickets Mappy2 et les workflows d'assistance demandent uniquement des informations utiles pour l'assistance ou la modération de JourneyMap.
- Éviter la collecte d'informations personnelles sensibles inutiles.
- Utiliser les jetons GitHub et autres informations d'identification uniquement en cas de besoin et avec le moins d'accès requis.
- Gérer qui a accès au tableau de bord Web Mappy2 et aux canaux Discord où Mappy2 publie des journaux ou des tickets.

## **Utilisation acceptable**

Vous ne pouvez utiliser Mappy2 que pour la gestion, l'assistance, la modération et l'administration légitimes de la communauté JourneyMap Discord.

Vous ne pouvez pas utiliser Mappy2 pour :

- Brisez les règles de Discord, les règles de GitHub ou les règles du serveur JourneyMap Discord.
- Harceler, menacer, maltraiter ou cibler des personnes.
- Envoyez du spam, du contenu de phishing, des logiciels malveillants, des liens trompeurs ou tout autre contenu nuisible.
- Collectez des mots de passe, des détails de paiement, des identifiants gouvernementaux ou d'autres informations hautement sensibles.
- Interférer avec Mappy2, Discord, GitHub ou d'autres services connectés.
- Tentative d'accès aux sections du tableau de bord, aux données du serveur, aux tickets d'assistance, aux informations d'identification ou aux enregistrements de modération auxquels vous n'êtes pas autorisé à accéder.
- Éviter les actions de modération, les contrôles de sécurité, les limites de débit ou les contrôles d'autorisation.

## **Modération et actions sur les tickets**

En fonction de la configuration de JourneyMap Discord et des actions du personnel, Mappy2 peut supprimer des messages, nettoyer les liens suspects, appliquer des délais d'attente ou désactiver des rôles, publier des journaux de modération, créer des canaux de réception de tickets privés, créer des fils de discussion de tickets de forum et créer des problèmes GitHub à partir du contenu du ticket.

Ces actions sont basées sur la configuration du bot, les autorisations Discord, les actions du personnel et les règles de modération automatisées. Le personnel de JourneyMap reste responsable de l’examen et de la gestion de la communauté.

## **GitHub Integration**

Si l'intégration GitHub est configurée, le personnel JourneyMap autorisé peut utiliser Mappy2 pour créer des problèmes GitHub à partir des fils de discussion de tickets Discord. Les réponses aux tickets, les liens de pièces jointes, les liens de fil de discussion Discord, les étiquettes de catégorie de ticket et les informations associées peuvent être envoyés au référentiel GitHub configuré lorsque cette action est utilisée.

Le personnel de JourneyMap est responsable de la configuration du référentiel correct, en utilisant les jetons GitHub appropriés et en s'assurant que le contenu du ticket est adapté au référentiel GitHub de destination.
