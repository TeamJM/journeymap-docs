
## **Installing**

JourneyMap peut être trouvé sur [CurseForge](https://www.curseforge.com/minecraft/mc-mods/journeymap) et [Modrinth](https://modrinth.com/mod/journeymap). Ce sont les seuls endroits légitimes pour le télécharger. Si vous le voyez sur un autre site Web, évitez de le télécharger à partir de là. Les copies de JourneyMap obtenues à partir de sources non officielles peuvent être anciennes, cassées ou contenir des virus, et elles violent notre licence.

## **Requirements**

JourneyMap 6.0 est publié pour plusieurs versions de Minecraft. Téléchargez le fichier qui correspond à votre version de Minecraft et à votre chargeur de mod, et assurez-vous que la bonne version de Java est installée.

| Version Minecraft | Java | Chargeurs de modules |
|-------------------|---------|-------------------------------|
| 1.21.1 | Java21 | Fabric, NeoForge, Forge |
| 1.21.11 | Java21 | Fabric, NeoForge, Forge |
| 26.1 | Java25 | Fabric, NeoForge, Forge |
| 26.2 | Java25 | Fabric, NeoForge, Forge |

Si vous ne disposez pas de la bonne version de Java, vous pouvez en télécharger une copie depuis le [site Web d'Adoptium](https://adoptium.net/temurin/releases/).

!!! note "Renderer"

    Les versions 1.21.1, 1.21.11 et 26.1 utilisent OpenGL de Minecraft
    moteur de rendu. La version 26.2 utilise le nouveau moteur de rendu Vulkan de Minecraft.

!!! note "Which loader?"

    JourneyMap est conçu pour Fabric, NeoForge et Forge. Choisissez celui qui
    chargeur que le reste de votre modpack utilise - JourneyMap ne nécessite pas de
    spécifique. Les pages CurseForge et Modrinth répertorient un fichier distinct
    pour chaque chargeur.

## **Textual Guide**

Si vous préférez un guide plus complet que vous pouvez lire et suivre à votre rythme, vous pouvez suivre ces instructions :

1. Décidez comment vous allez travailler avec Minecraft. Certaines options incluent (de la plus simple à la plus difficile) :
- [Le lanceur CurseForge](https://download.curseforge.com/)
- [Lanceur de prisme](https://prismlauncher.org/)
- [Le lanceur officiel de Minecraft](https://www.minecraft.net/download)

Nous recommandons Prism Launcher pour sa facilité d'utilisation, mais n'importe quel lanceur fonctionnera très bien.

2. Assurez-vous que la bonne version de Java est installée pour votre version de Minecraft (voir le tableau ci-dessus). Sinon, vous pouvez en télécharger une copie depuis le [site Web d'Adoptium](https://adoptium.net/temurin/releases/).

3. Installez votre chargeur de mod. Utilisez Fabric, NeoForge ou Forge - selon celui utilisé par votre modpack. Vous pouvez consulter le journal des modifications de la version de JourneyMap que vous téléchargez pour voir quelle version du chargeur nous avons construite et testée.
- Si vous utilisez [le lanceur officiel de Minecraft](https://www.minecraft.net/download), exécutez le programme d'installation du chargeur de votre choix et sélectionnez la version de Minecraft souhaitée.
- Si vous utilisez [Prism Launcher](https://prismlauncher.org/), créez une nouvelle instance pour la version de Minecraft que vous souhaitez utiliser, modifiez cette instance, sélectionnez Version sur la gauche et ajoutez le chargeur de mod de votre choix.
- Si vous utilisez [le CurseForge Launcher](https://download.curseforge.com/), cliquez sur Mods en haut, sélectionnez Minecraft et créez un nouveau profil avec la version de Minecraft et le chargeur souhaité.

4. Téléchargez JourneyMap depuis [CurseForge](https://www.curseforge.com/minecraft/mc-mods/journeymap/files) ou [Modrinth](https://modrinth.com/mod/journeymap)», en choisissant le fichier correspondant à votre version Minecraft et à votre chargeur de mod.
- Si vous utilisez [le CurseForge Launcher](https://download.curseforge.com/), vous pouvez cliquer sur le bouton Installer à côté de la version que vous souhaitez utiliser et elle sera installée pour vous. Sinon, cliquez sur le bouton de téléchargement et attendez que le téléchargement du JAR soit terminé.
- Si vous utilisez [Prism Launcher](https://prismlauncher.org/), modifiez l'instance que vous utilisez, sélectionnez Mods à gauche et faites glisser et déposez le JAR que vous avez téléchargé dans la liste de droite.
- Si vous utilisez [le lanceur officiel de Minecraft](https://www.minecraft.net/download), recherchez le dossier `mods` pour votre profil modifié et copiez-y le JAR que vous avez téléchargé.

Si aucun téléchargement n'est disponible pour votre version de Minecraft, c'est que nous n'en avons pas encore publié ! Soyez patient - JourneyMap est un mod volumineux et compliqué et il nous faut beaucoup de temps pour le porter sur les nouvelles versions de Minecraft.

5. C'est tout, vous avez terminé - lancez le jeu et JourneyMap devrait être disponible !

## **Webmap**

La carte Web, qui vous permet de visualiser votre carte dans un navigateur Web, était intégrée à JourneyMap. Depuis JourneyMap 6.0, il s’agit d’un module complémentaire distinct. Si vous le souhaitez, installez-le avec JourneyMap - voir [Webmap > Installing](../webmap/installing.md).
