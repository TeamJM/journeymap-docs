    Mappy2 Privacy Policy

    Last updated: 16 Juin, 2026

    Cette politique de confidentialité explique quelles données Mappy2 traite, pourquoi elles sont utilisées, comment elles peuvent être partagées et comment demander leur suppression.

    Mappy2 est un bot Discord privé et un outil d'administration Web exploité par Mysticdrew pour être utilisé au sein du serveur JourneyMap Discord. Il prend en charge la gestion de la communauté JourneyMap, l'assistance à la modération, les commandes personnalisées, la prise de tickets, les flux de travail de support et la création facultative de problèmes GitHub.

    Mappy2 est une infrastructure JourneyMap privée. Il n'est pas proposé en tant que plate-forme ou service de robots à usage général pour les serveurs Discord tiers.

    Pour des questions de confidentialité ou des demandes de données, contactez Mysticdrew sur le serveur Discord JourneyMap.

    Data Mappy2 Processes

    Mappy2 traite uniquement les données nécessaires pour fournir ses fonctionnalités de modération JourneyMap Discord, de ticket, de commande, de GitHub et de tableau de bord Web.

    Compte Discord et données de connexion

    Lorsqu'un membre autorisé du personnel JourneyMap se connecte au tableau de bord Web Mappy2 avec Discord OAuth, Mappy2 peut traiter :

    • ID utilisateur Discord.
    • Nom d'utilisateur Discord, nom d'affichage, discriminateur, identifiant d'avatar et données de profil associées renvoyées par Discord.
    • Jeton d'accès Discord OAuth pour la session Web active.
    • Liste des guildes Discord et données d'autorisation de guilde renvoyées par Discord afin que Mappy2 puisse déterminer l'accès au tableau de bord.

    Mappy2 utilise ces données de connexion uniquement pour l'administration de JourneyMap. Il n'est pas utilisé pour assurer la gestion des robots pour les serveurs Discord tiers.

    Serveur JourneyMap et données de configuration

    Mappy2 peut stocker des données de configuration pour le serveur JourneyMap Discord, notamment :

    • ID de guilde Discord.
    • ID de canal, ID de rôle, ID de message et ID de fil utilisés par les fonctionnalités de Mappy2.
    • Noms de commandes, réponses de commandes, intégrations et paramètres de commandes créés par le personnel autorisé de JourneyMap.
    • Paramètres de modération tels que le préfixe de commande, le canal du journal de modération, le canal du journal des membres, le rôle désactivé, les paramètres de protection anti-spam et les paramètres de désinfection des liens de démarque.
    • Paramètres du panneau de tickets, de la catégorie, de la question, de la validation, du canal du forum, du canal d'admission et du canal de journalisation.
    • Enregistrements d'administrateur du tableau de bord Mappy2, autorisations du tableau de bord et enregistrements d'accès à la guilde.
    • Paramètres facultatifs du référentiel GitHub et données de jeton GitHub configurés par le personnel autorisé de JourneyMap.

    Moderation Data

    Lorsque les fonctionnalités de modération sont activées, Mappy2 peut traiter le contenu des messages et les métadonnées sur le serveur JourneyMap Discord pour détecter le spam, nettoyer les liens, supprimer les messages, appliquer des actions de modération et publier des journaux de modération.

    Mappy2 peut stocker des enregistrements d'observations de modération tels que :

    • ID de guilde Discord, ID utilisateur, ID de chaîne et ID de message.
    • Type de message.
    • Hachages ou empreintes digitales dérivés du texte d'un message, de liens ou de pièces jointes normalisés.
    • Si un message contenait un lien de style démarque.
    • Enregistrements d'actions de modération, codes de motif et métadonnées d'action.

    Les enregistrements d'observation de spam de Mappy2 sont destinés à la détection du spam à court terme et sont automatiquement nettoyés après la fenêtre de rétention configurée. La fenêtre de rétention par défaut est d'environ 6 heures.

    Mappy2 peut également publier des messages de journal de modération dans les canaux JourneyMap Discord configurés. Ces messages Discord sont stockés et contrôlés par Discord et par le processus de modération JourneyMap Discord.

    Ticket Data

    Lorsqu'un utilisateur ouvre ou complète un ticket de support JourneyMap géré par Mappy2, Mappy2 peut stocker :

    • ID de guilde Discord et ID utilisateur.
    • Catégorie de ticket et identifiants de panneau.
    • Statut et progression du ticket.
    • Réponses aux questions sur les billets.
    • Métadonnées des pièces jointes et URL des pièces jointes Discord incluses avec les réponses au ticket.
    • ID de canal d'admission, ID de message d'invite, ID de canal de forum, ID de fil de discussion et ID Discord associés.
    • GitHub émet des URL si un ticket est envoyé à GitHub.

    Les réponses aux tickets peuvent contenir des informations que l'utilisateur choisit de soumettre au support JourneyMap. Les utilisateurs doivent éviter de soumettre des mots de passe, des détails de paiement, des identifiants gouvernementaux, des clés privées ou d'autres informations personnelles hautement sensibles.

    Données d'audit et d'activité du personnel

    Mappy2 peut stocker des enregistrements d'audit pour le tableau de bord et les actions administratives effectuées par le personnel autorisé de JourneyMap, notamment :

    • ID utilisateur Acting Discord.
    • ID de guilde. -Type d'action.
    • Type de cible et ID cible.
    • Détails des actions nécessaires à la responsabilité et au dépannage.

    How Mappy2 Uses Data

    Mappy2 utilise les données pour :

    • Authentifiez le personnel JourneyMap autorisé via Discord.
    • Déterminez à quelles sections du tableau de bord un membre du personnel peut accéder.
    • Stockez et appliquez la configuration du bot JourneyMap Discord.
    • Exécutez des commandes personnalisées sur le serveur JourneyMap Discord.
    • Détectez le spam et les liens suspects.
    • Appliquer les actions de modération configurées.
    • Créez, gérez et archivez les flux de travail des tickets d'assistance JourneyMap.
    • Publier les journaux de modération, de tickets, de membres et d'administration si configurés.
    • Créez des problèmes GitHub à partir des fils de discussion lorsque le personnel autorisé de JourneyMap utilise cette fonctionnalité.
    • Dépanner, sécuriser, maintenir et améliorer Mappy2.

    Mappy2 ne vend pas de données personnelles et n'utilise pas de données personnelles à des fins publicitaires.

    Partage et tiers

    Mappy2 peut partager ou transmettre des données dans les cas suivants :

    • Discord : Mappy2 utilise les API Discord et fonctionne au sein du serveur JourneyMap Discord. Les messages, journaux, tickets, rôles, canaux, fils de discussion, données OAuth et autres données Discord sont également soumis aux propres politiques de Discord.
    • GitHub : Si l'intégration de GitHub est configurée et que le personnel JourneyMap autorisé crée un problème GitHub à partir d'un ticket, Mappy2 envoie le contenu du ticket sélectionné, les liens de pièces jointes, les étiquettes et les liens de fil de discussion Discord au référentiel GitHub configuré.
    • Fournisseurs d'hébergement et d'infrastructure : Mappy2 peut fonctionner sur l'infrastructure d'hébergement, de base de données, de journalisation, de sauvegarde ou de réseau nécessaire au fonctionnement du service.
    • Raisons juridiques ou de sécurité : Les données peuvent être divulguées lorsque la loi l'exige, pour protéger les utilisateurs, enquêter sur une utilisation abusive ou pour protéger Mappy2 et les services connectés.

    Mappy2 ne vend pas les données de l'API Discord et ne les partage pas avec des réseaux publicitaires ou des courtiers de données.

    Retention

    La conservation dépend du type de données et de la manière dont Mappy2 est utilisé dans le serveur JourneyMap Discord :

    • Les données de session OAuth sont conservées pour la session active du tableau de bord et expirent ou sont effacées lorsque l'utilisateur se déconnecte ou que la session se termine.
    • Les données d'accès à la guilde Discord mises en cache sont de courte durée et utilisées pour réduire les appels répétés de l'API Discord.
    • Les enregistrements d'observation de spam sont automatiquement nettoyés après la fenêtre de rétention configurée. La valeur par défaut est d'environ 6 heures.
    • La configuration de JourneyMap Discord, les commandes personnalisées, les autorisations du personnel, la configuration des tickets, les enregistrements de tickets, les événements de modération et les journaux d'audit sont conservés lorsque cela est nécessaire pour faire fonctionner Mappy2, prendre en charge l'administration de JourneyMap ou conserver l'historique de modération et de support.
    • Les messages et journaux Discord publiés par Mappy2 restent dans Discord jusqu'à ce qu'ils soient supprimés dans le cadre du processus de modération JourneyMap Discord.
    • Les problèmes GitHub créés par Mappy2 restent dans GitHub jusqu'à ce qu'ils soient supprimés ou modifiés dans GitHub.

    Les données peuvent être supprimées plus tôt lorsqu'elles ne sont plus nécessaires, lorsque Mysticdrew ou le personnel autorisé de JourneyMap demande la suppression, ou lorsque la suppression est requise par la loi applicable ou la politique de la plateforme.

    Deletion Requests

    Pour demander la suppression des données stockées sur Mappy2, contactez Mysticdrew sur le serveur Discord JourneyMap.

    Veuillez inclure suffisamment d'informations pour trouver les données pertinentes, telles que :

    • Votre identifiant Discord.
    • Le ticket, la commande, l'événement de modération ou l'enregistrement du tableau de bord impliqué, s'il est connu.
    • La date approximative ou la chaîne concernée, si connue.

    Certaines données peuvent également exister dans les canaux Discord, les journaux Discord, les problèmes GitHub, les sauvegardes ou d'autres systèmes tiers. Mappy2 ne peut contrôler directement les données qu'il stocke ou publie que via les comptes qu'il exploite. Le personnel de JourneyMap devra peut-être supprimer les messages Discord ou le contenu GitHub séparément.

    Security

    Mappy2 utilise les contrôles d'accès et les autorisations Discord pour limiter les actions du tableau de bord et des robots au personnel autorisé de JourneyMap. L’accès au tableau de bord et au canal Discord ne doit être accordé qu’au personnel de confiance.

    Aucun système n’est parfaitement sécurisé. Ne soumettez pas de mots de passe, de détails de paiement, de clés privées, d'identifiants gouvernementaux ou d'autres informations personnelles hautement sensibles via des tickets, des commandes ou des champs de configuration Mappy2.

    Children

    Mappy2 est destiné à être utilisé dans Discord et dépend des comptes Discord. Les utilisateurs doivent répondre aux exigences d'âge minimum de Discord et aux règles du serveur JourneyMap Discord.

    Policy Changes

    Cette politique de confidentialité peut être mise à jour de temps à autre. L'utilisation continue de Mappy2 après la publication des modifications signifie que la politique mise à jour s'applique.

    Contact

    Pour toute question, préoccupation ou demande de données, contactez Mysticdrew sur le serveur Discord JourneyMap.
